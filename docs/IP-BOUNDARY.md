# qFoldIT Realtime Validation IP Boundary

CAMEO-REALTIME-VALIDATION is part of the qFoldIT execution-to-science evidence boundary.

## Corporate material

Production reconciliation logic, private policy implementations, customer-specific integrations, confidential runtime telemetry and deployment configuration are qFoldIT corporate material and belong in private infrastructure.

## Open-source material

Previously released source remains governed by its applicable published license. This document does not retroactively revoke rights granted by an existing license.

## Scientific boundary

Realtime runtime events are not, by themselves, scientific evidence. Scientific evidence is produced by the configured validation authority and recorded through the qFoldIT evidence contract with explicit provenance.

## Release evidence

Production releases should record repository, commit SHA, author, review reference, release identifier, artifact hashes and the corresponding qFoldIT IP evidence registry version.
